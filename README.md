markdown# 🔞 The Language of Love Trainer (Multi-Language PWA)

Welcome to the official repository for the **Language of Love Trainer**! This interactive, privacy-focused web application is an educational vocabulary puzzle designed for adults, couples, and language learners who want to confidently master romantic, intimate, and bedroom communication across five European languages.

🚀 **Play the Live Web App Now:** [👉 Click Here to Start Learning](https://github.io)

### 🌶️ The Heat Index Framework
The application divides phrases into three distinct situational tiers, allowing you to tailor your learning pace seamlessly to your environment:
* 🟢 **Mild (Romancing):** Lighthearted flirting, sweet compliments, and pacing commands. Perfect for public commutes or setting a romantic scene.
* 🟡 **Spicy (Intimate):** Deep sensual desire, heavy teasing, and anatomical phrases to build anticipation.
* 🔴 **Fire (Bedroom):** Direct physical directives, bedroom commands, and climax communication.

### 📱 Premium Mobile App Experience (PWA)
This project is built as a **Progressive Web App**. When you open the live link on an iPhone or Android device, you can use your browser menu to select **"Add to Home Screen."** 
* Installs instantly with its own full-screen dashboard icon.
* Features a robust caching layer for **100% offline-ready practice** with no mobile data required.
* Completely free from annoying corporate ads or tracking cookies.
